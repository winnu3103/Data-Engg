Storage & Database Foundations

1. Storage Types

Database (OLTP DB)

Organized storage for running applications. Row-based. Optimized for fast reads/writes.

Data Warehouse (DWH)

Centralized repository for analytics. Columnar storage. Examples: Snowflake, BigQuery.

2. Row-Oriented vs. Columnar Storage

Dimension Row-Oriented (OLTP) Columnar (OLAP)
Best for Reading or writing a single row quickly. Aggregating massive columns.
